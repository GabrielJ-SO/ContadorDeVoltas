# __Contador De Voltas__ v1.0.0
Projeto de contador de voltas para pistas de treinamento.

---

## Sobre o Projeto
O projeto foi desenvolvido para automatizar e facilitar a contagem de voltas em pistas de corrida, permitindo que o atleta dedique sua concentração ao treino.

### Funcionalidades
- __Displays__: Controle de voltas e tempo de treino em pista em tempo real.
- __API__: Opção de salvar treino em banco de dados.
  
---

## Tecnologias Utilizadas
### Componentes de Hardware:
* Microcontrolador: Arduino UNO R4 WiFi
* Sensor: Dois Sensores infravermelho Intelbras IVA 5015
* Display: Matriz de Led 24x32 max7219
### Software e Firmware
* C++ (Arduino)
* API String Boot Java
* Banco de dados MySQL
